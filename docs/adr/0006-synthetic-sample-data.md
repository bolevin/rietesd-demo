# 0006 — Ship synthetic sample data only

Status: accepted

## Context

A demonstration needs a pattern to load, and the tests need a fixed input. Measured
patterns belong to the people who measured them and to work that may be unpublished.

## Decision

The repository contains one pattern, generated by `tools/make_sample.py` with a fixed seed:
a simulated Cu Kα1 scan of a cubic perovskite with a minor second phase, 10–120° in steps
of 0.02°. "Observed" counts are Poisson noise around a model that differs slightly from the
"calculated" one in peak widths, positions, intensities and asymmetry.

## Consequences

- Nothing in the repository, the screenshots or the tests is anyone's measurement.
- The misfit is built in on purpose: it produces the runs of same-sign residuals the
  program exists to detect (*d* ≈ 1.02 against *Q* ≈ 1.93, coefficient ≈ 2.28).
- The file is reproducible byte for byte; its SHA-256 is stored with the reference values.
- The layout is exactly what TOPAS v.5 exports, including phase and peak columns the demo
  ignores, so the same file loads in the full program — which is how the reference values
  are recorded.
- A synthetic pattern does not show every difficulty of real data.
